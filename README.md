# 🐾 Meowroush Polo

A personal corner of the internet.

This project is my attempt to build a quiet place for travel stories, photographs, and memories from the road.

## What it is

Meowroush Polo is a travel journal where I can:

* Share photographs from places I've visited
* Write short stories and reflections
* Document adventures, hikes, and everyday moments
* Build a collection of memories that grows over time


## Current Status

🚧 Work in progress

The project is actively being developed and will continue evolving as new trips, ideas, and features are added.

## Planned Features

* Photo galleries
* Travel stories and journal entries
* Interactive maps
* Search and archive system
* Responsive design
* Dark mode
* User accounts and community contributions

## Tech Stack

* Astro
* TypeScript
* Plain CSS
